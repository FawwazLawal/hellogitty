Why this lit. GitHub's REST and GraphQL APIs share a 5,000-point hourly budget per token. HelloGitty's refresh costs about 45 points, so the dashboard alone takes under 1% an hour. A spike almost always means another tool is using the same token.

What to do. Wait for the reset time above — the counter clears at the top of the hour. If the alert keeps lighting between resets, check what else is calling GitHub with the same token (a CI job, a scripts folder, a browser extension that signed in), and either narrow the tracked repository list in Settings or give that other tool its own token. HelloGitty automatically slows its own polling when the quota is near empty.

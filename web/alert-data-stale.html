Why this lit. The last check of GitHub is more than two hours old. HelloGitty keeps the dashboard showing what it last fetched; a stale number is still accurate at the time it was gathered.

What to do. Most stale alerts clear themselves on the next poll — the dashboard refreshes automatically. If the counter does not move on refresh: check that your computer has network, then that your GitHub token is still valid (Settings → Account). If a specific repository's check keeps failing, it will appear in Check failed; a missing token or an expired one goes into the server log.
